# 운석피하기

우주 공간에서 운석을 피하며 최대한 오래 생존하는 1인 회피 게임.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173

## 해상도

- 게임 월드(좌표계): **1920×1080** (Full HD)
- 실제 캔버스는 **화면에 나오는 크기 그대로** 잡고 좌표만 배율로 맞춘다 — 판 크기로 그린 뒤
  CSS 로 줄이면 글씨·가는 선이 한 번 더 축소되며 흐려진다(`src/display.ts`)
- Retina/고DPI: `devicePixelRatio` 최대 2× 적용
- 창 크기에 맞게 비율 유지하며 전체 화면 표시

## 조작

- **방향키** 또는 **WASD** — 이동
- **SPACE** / **클릭** — 시작 / 재시작
- **R** — 게임 오버 후 재시작

## 규칙

- 스킬 없음 — 이동만 가능
- 생존 시간 = 점수 (섹터별 배율 적용)
- 시간이 지날수록 운석 종류·속도·개수 증가

## 운석 종류

| 시간 | 타입 |
|------|------|
| 0s~ | 일반 |
| 15s~ | 소형 파편 |
| 30s~ | 대형 |
| 45s~ | 회전 |
| 60s~ | 궤도 |
| 75s~ | 분열 |
| 90s~ | 가속 |
| 120s~ | 벨트 |
| 150s~ | 혜성 (머리만 위험) |
